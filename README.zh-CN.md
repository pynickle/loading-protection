# Loading Protection

给玩家一段短暂的加载保护，避免世界刚显示出来、但还没真正稳定时就先挨打。

[English README](./README.md)

> [!IMPORTANT]
> 本模组面向 **Minecraft 26.1+**。

## 概览

Loading Protection 会在玩家进入世界、重生或跨维度后，给出一小段保护时间。它解决的就是那几秒钟的空档：画面已经出来了，但区块、实体或者联机状态可能还没完全稳定，伤害却已经开始结算。

保护生效期间，模组可以：

- 避免玩家在刚加入、重生或传送后立刻受伤
- 清除敌对生物对受保护玩家的锁定
- 阻止受保护玩家在保护结束前主动造成伤害
- 在玩家真正移动后提前结束保护
- 通过聊天栏、Action Bar 或两处同时显示倒计时提示

## 适用场景

这个模组尤其适合下面这些情况：

- 玩家刚进服务器，附近怪物已经开始行动，但客户端还在加载
- 重生时有卡顿，结果人还没站稳就又死一次
- 跨维度传送完成了，目标区域却还没完全稳定
- 生存服或冒险服想让登录、重生和传送过程更平滑一些

## 触发方式

保护可以在以下时机触发：

- 加入世界或服务器
- 重生后
- 跨维度切换后

默认只在**加入世界 / 服务器**时触发。重生和跨维度保护可以按需开启。

## 保护期间会发生什么

按默认设置，受保护玩家会有这些效果：

- 不会受到伤害
- 敌对生物会失去对玩家的锁定
- 不能对玩家或生物造成伤害
- 保护持续时会收到倒计时提示

如果开启了“位移即结束”，玩家只要真的改变位置，保护就会立刻结束；单纯转视角不算。

## 配置

配置文件位置：

```text
config/loadingprotection-common.toml
```

主要选项包括：

- `Protection Duration`：保护时长，范围 1-300 秒
- `Trigger On Join`：加入世界或服务器时触发保护
- `Trigger On Respawn`：重生后触发保护
- `Trigger On Dimension Change`：跨维度后触发保护
- `End On Movement`：玩家实际移动后结束保护
- `Protect Mount`：同时保护当前骑乘的载具
- `Prevent Mob Targeting`：阻止敌对生物持续锁定玩家
- `Prevent Outgoing Damage`：阻止受保护玩家主动攻击
- `Show Messages`：显示开始、倒计时和结束提示
- `Message Mode`：提示显示在聊天栏、Action Bar 或两处同时显示

## 默认行为

模组默认采用一套比较稳妥的设置：

- 保护持续 **60 秒**
- 玩家**加入世界 / 服务器**时触发保护
- 玩家移动后提前结束保护
- 清除敌对生物锁定
- 阻止玩家主动造成伤害
- 同时在聊天栏和 Action Bar 显示提示
